# InDivoice

InDivoice is a CPU-capable research system for classifying an audio recording as genuine human speech or AI-generated synthetic speech in Hindi, Tamil, and Bengali. It uses log-Mel spectrogram features and a small convolutional neural network, and evaluates cross-language generalization and robustness to compression, background noise, and synthesis systems not seen during training. A minimal web interface will expose a prediction and confidence indication while clearly communicating uncertainty and limitations.

## Research questions

1. How reliably does a compact log-Mel/CNN detector generalize across Hindi, Tamil, and Bengali?
2. How does performance change under audio compression and background noise?
3. How well does the detector identify speech generated by synthesis systems absent from training?
4. What false-positive rate is observed on genuine speech from independent corpora not used for training?
5. How much do speaker, corpus, and recording-condition splits affect the apparent result?

## Limitations and intended use

InDivoice is a research demo for defensive scam-risk assessment, not a forensic or authentication system. Synthetic speech does **not** imply fraud, malicious intent, or wrongdoing; genuine speech is **not necessarily trustworthy**. Predictions can be wrong, especially for languages, speakers, codecs, microphones, and synthesis systems outside the evaluation data. The tool must not be used as the sole basis for financial, legal, employment, safety, identity, or access decisions, and it does not store user uploads. Dataset use is subject to the individual source licenses; IndicSynth is CC BY-NC 4.0, so this project is research/non-commercial unless permissions are separately obtained.

## Quick start

Python 3.10+ is supported. For a clean CPU environment:

```bash
make install
make test
```

Useful commands are listed in the `Makefile`. Phase 1 intentionally contains infrastructure only; no dataset has been downloaded and no scientific metric has been produced.

## Project layout

- `configs/` — versioned YAML configuration by concern
- `src/indivoice/` — package code
- `scripts/` — command-line entry points for future phases
- `tests/` — automated tests
- `docs/` — status, decisions, and dataset provenance template
- `results/` — only outputs from real, recorded runs
